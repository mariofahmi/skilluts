Katalog 61 Mata Kuliah PPKn (Semester 1–8)

Pilih semester untuk melihat seluruh daftar naskah UTS yang telah disusun secara presisi sesuai RPS kurikulum OBE.

Keunggulan Engine

Arsitektur Generator Soal UTS

Dirancang untuk menghasilkan naskah ujian yang presisi, aman dari kerusakan XML, dan memenuhi standar mutu OBE.

Preservasi Struktur Master Template Word XML

Tidak membangun dokumen dari nol. Engine menggunakan teknik injeksi token XML yang menjaga posisi logo ber-anchor (floating image), kop surat resmi kampus, dan properti tabel tetap utuh 100%.

Taksonomi Bloom (C2–C6)

Butir soal otomatis dikonstruksi secara analitis dari materi pertemuan 1–7 RPS dengan Kata Kerja Operasional yang terukur.

Dual Output (DOCX & MD)

Menghasilkan berkas Word `.docx` siap cetak sekaligus Markdown `.md` untuk integrasi ke portal LMS dan dokumentasi repositori.

Lintas Platform & Bebas Ketergantungan CLI

Ditenagai modul standar Python murni (`zipfile` & `tempfile`). Berjalan lancar di Windows, macOS, maupun Linux tanpa memerlukan software eksternal zip/unzip.

Cara Penggunaan

Instalasi ke Antigravity IDE

Gunakan skill ini dalam hitungan detik di antarmuka coding AI Anda.

Panggil langsung di chat Antigravity IDE:

/uts-unirow @RPS_Mata_Kuliah.docx

Clone repositori ke folder skills Antigravity:

git clone https://github.com/mariofahmi/skilluts.git .agents/skills/uts-unirow

Jalankan via terminal Python:

py scripts/fill_uts.py "Naskah_UTS.docx" --data "data.json"
Teks berhasil disalin!
